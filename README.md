## 📌 Highlighted Projects

### 🛒 [**BookStore – E-commerce Platform**](https://github.com/duykhoa1125/bookstore)
A full-stack web application for browsing, purchasing books online, and managing orders.
- **Tech Stack**: React 18, Vite, TailwindCSS, Node.js, Express 5, PostgreSQL, Prisma ORM.
- **Key Features**: 
  - Comprehensive authentication with JWT and Google OAuth 2.0.
  - Multi-role permission system (User/Admin) securing frontend routes and backend APIs.
  - Complete checkout flow, order tracking, and integration with Resend/Cloudinary.
  - Interactive rating/voting system and admin dashboard with Recharts analytics.

### 🎟️ [**Movie Ticket Booking System**](https://github.com/duykhoa1125/ticket-booking-system)
A high-performance online ticket booking system modeling CGV/Lotte Cinema workflows, heavily focusing on advanced Database concepts.
- **Tech Stack**: Next.js 16 (App Router), React 19, Tailwind CSS v4, Node.js, MySQL.
- **Key Features**:
  - Deep utilization of RDBMS (MySQL) 3NF design, Triggers, Stored Procedures, and Functions to offload business constraints directly to the database.
  - Robust multi-step booking logic with transaction handling ensuring data integrity.
  - Automated tier-based voucher systems and hierarchy-based promotional tracking.
